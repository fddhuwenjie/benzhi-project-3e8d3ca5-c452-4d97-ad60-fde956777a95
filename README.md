# 探方回填封护验收台

探方回填封护验收台面向考古现场记录员、遗址保护负责人和独立验收员。系统把已完成发掘记录的探方纳入封护案件，冻结可追溯基线，编制并批准分层回填方案，登记施工检测数据，按确定性规则识别缺陷并完成定向复验，最后由职责独立的验收员生成不可变封护档案。

根路径工作台提供案件检索和待办统计，并沿用同一单案闭环完成以下操作：

- 冻结前字段预检、确认摘要、冻结凭证和后续基线完整性比较；
- 方案总厚度、逐层参数、相邻层变化和风险确认后批准；
- 当前施工层草稿、待补字段恢复、草稿版本与案件版本双重核对；
- 五项施工规则的实际输入、阈值、通过状态、数值余量和提交时快照；
- 整改方案登记、措施完成、定向复验及历次失败尝试留痕；
- 结构化验收退回问题、分别整改和多轮独立验收历史；
- 封存档案下载、只读时间线以及带稳定检查代码的分项校验报告。

## 构建

```text
go build ./cmd/siteclosure
```

## 运行

```text
go run ./cmd/siteclosure -addr=127.0.0.1:19081
```

服务默认监听 `127.0.0.1:19081`，可用 `-addr=127.0.0.1:<port>` 指定其他高位回环端口，并使用 `-data` 指定本地 JSON 快照和事件帧目录。

## 测试

```text
go test ./...
go run ./cmd/siteclosure -selftest -addr=127.0.0.1:19081
```

`-selftest` 会启动真实 HTTP 服务，通过浏览器使用的同源 JSON 路由走完建档、基线冻结、方案批准、逐层施工、独立验收、案件总览和档案分项校验，然后主动退出。
